# Getting started

Use this path to prepare for your first Agent change. The linked pages contain the setup instructions and contribution requirements.

1. Set up the [required development tools](dev/env/setup/required.md). Review the [optional tools](dev/env/setup/optional.md), or use [manual setup](dev/env/setup/manual.md) when you need to work outside the provided environments.
1. Follow the [developer environment tutorial](dev/env/dev/usage.md) to work in a configured environment.
1. [Build a standalone Agent](dev/build/standalone.md) and learn how to [run unit tests](dev/test/unit.md).
1. Find the relevant framework or subsystem in [Implementation](impl/index.md). Its topic overview points to the concepts, procedures, and conventions you need.
1. Read the [contribution checklist](contrib/index.md#pull-requests) before preparing your PR.

For a specific task, use the [topic directory](topic.md) or [learning paths](learn.md).
