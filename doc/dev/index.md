# Development workflow

Development workflow explains how to perform and validate development work. Each activity brings its procedures, infrastructure descriptions, troubleshooting guidance, and tool reference together.

| Activity | Start here |
| --- | --- |
| Environments | Install the [required tools](env/setup/required.md), follow the [developer environment tutorial](env/dev/usage.md), or use a [lab environment](env/lab/index.md). |
| Building | Build [standalone agents](build/standalone.md) or [distribution packages](build/package.md), and consult the [Agent buildables](build/component.md). |
| Testing | [Choose a test approach](test/category.md), [run unit tests](test/unit.md), use [end-to-end tests](test/e2e/index.md), or perform [manual QA](test/qa/index.md). |
| Debugging | [Debug an Agent](debug/agent/index.md) or investigate its [memory use](debug/memory/index.md). |
| Maintaining tooling | Build, preview, and maintain the [documentation platform](tool/doc.md). |

For guidance on changing a framework or subsystem, see [Implementation](../impl/index.md). For requirements that apply to a contribution, see [Contributing](../contrib/index.md).
