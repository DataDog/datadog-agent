# Archived GenSim global 1 Hz corpus artifacts — 2026-08-25

These files preserve the pre-outcome-blind corpus search and superseded smoke plans.
They are historical evidence only and are not active launch, admission, or dataset
membership inputs.

The corpus artifacts were retired because they mixed source admission, plumbing
capability, and experimental outcomes. Their replacements use outcome-blind
admission: successful source provenance and quality, static telemetry
classification, runnable/safe execution, and capability-smoke readiness. A
pre-existing 1 Hz advantage, counterfactual result, or RCA improvement is not an
admission requirement.

The pilot and smoke artifacts were already explicitly superseded by
`docs/dev/gensim-global-1hz-episode-ctl-campaign-plan.md`. The retroactive smoke
plan is retained only for historical design context.
